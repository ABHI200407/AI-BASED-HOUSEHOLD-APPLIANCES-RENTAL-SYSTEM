# Data Models (MongoEngine Documents)

## User (users app)
- email (StringField, unique, required)
- password (StringField, hashed, required)
- full_name (StringField)
- role (StringField, choices: 'admin', 'owner', 'tenant', required)
- phone (StringField)
- address (StringField)
- date_joined (DateTimeField, auto_now_add)

## Appliance (appliances app)
- owner_id (ReferenceField User)
- name (StringField, required)
- category (StringField, e.g. 'AC', 'Refrigerator', 'Washing Machine', 'Microwave', 'TV', required)
- description (StringField)
- price_per_day (FloatField, required)
- images (ListField of StringField — local file paths)
- location (StringField)
- available (BooleanField, default True)
- created_at (DateTimeField, auto_now_add)

## Booking (bookings app)
- tenant_id (ReferenceField User)
- appliance_id (ReferenceField Appliance)
- start_date (DateTimeField, required)
- end_date (DateTimeField, required)
- status (StringField, choices: 'requested', 'approved', 'active', 'returned', 'cancelled')
- total_amount (FloatField)
- created_at (DateTimeField, auto_now_add)

## RecommendationLog (ml_recommend app)
- tenant_id (ReferenceField User)
- appliance_id (ReferenceField Appliance)
- score (FloatField)
- method (StringField, 'content_based' or 'collaborative')
- generated_at (DateTimeField, auto_now_add)

## DemandForecast (ml_forecast app)
- category (StringField)
- forecast_date (DateTimeField)
- predicted_units (FloatField)
- model_version (StringField)
- generated_at (DateTimeField, auto_now_add)

## ChurnScore (ml_churn app)
- tenant_id (ReferenceField User)
- risk_score (FloatField, 0-1)
- risk_level (StringField, 'Low'/'Medium'/'High')
- recency_days (IntField)
- frequency_count (IntField)
- monetary_total (FloatField)
- calculated_at (DateTimeField, auto_now_add)

Note: these are the MINIMUM required fields. Antigravity may add indexes, validators, or
helper methods, but must not remove or rename these core fields without flagging it back.
